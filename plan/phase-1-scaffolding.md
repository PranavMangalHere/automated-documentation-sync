## Step-by-Step Instructions

### Step 1.1 — Initialize Git Repository

```bash
git init
git branch -M main
```

### Step 1.3 — Create `.gitignore`

Standard Python `.gitignore` covering:

* `__pycache__/`, `*.pyc`, `*.pyo`, `*.pyd`
* `.env`, `.venv`, `venv/`, `env/`
* `.pytest_cache/`, `.mypy_cache/`, `.ruff_cache/`

### Step 1.4 — Create `pyproject.toml`

Minimal project metadata:

```toml

name = "automated-documentation-sync"

version = "0.1.0"

description = "Agentic SDLC pipeline driven by GitHub Copilot"

requires-python = ">=3.11"

[tool.pytest.ini_options]

testpaths = ["tests"]

[tool.ruff]

line-length = 88
```

No runtime dependencies yet — the implementation agent will add them in Phase 5.

---

### Step 1.5 — Create `.github/copilot-instructions.md`

This file contains the project-wide instructions that GitHub Copilot should follow when working in this repository.

It must explain:

**Sections to include:**

1. **Project Overview** — one paragraph on what this pipeline is and why it exists.

2. **How to Run the Pipeline** — explain how the user starts the orchestrator and provide the expected invocation:

```text
@orchestrator process user-stories/<filename>.md
```

3. **Pipeline Phases** — brief description of each of the 9 agents in order.

4. **Interaction Levels** — explain:

   * L1 — Deep Interactive
   * L2 — Run + Approve
   * L3 — Explicit Approve

5. **File Conventions** — where artifacts live and naming rules for user story files.

6. **Do Not** — list things Copilot should never do:

   * Invoke specialist agents directly when the orchestrator should coordinate them.
   * Skip gating checks.
   * Skip required pipeline stages.
   * Modify artifacts belonging to another stage without following the pipeline.
   * Create the PR without user confirmation.

---

### Step 1.6 — Create `README.md`

User-facing documentation.

Sections:

1. **What This Is** — 2–3 sentence overview.

2. **Quick Start** — 4-step guide:

   * Clone the repository.
   * Add a user story.
   * Invoke the orchestrator.
   * Follow the Copilot prompts/approval steps.

3. **Pipeline Architecture** — ASCII diagram of the flow.

4. **Folder Structure** — annotated tree.

5. **Agent Reference** — table of all 9 agents with their role and interaction level.

6. **Requirements** — GitHub Copilot, VS Code, Git, and Python version.

7. **Contributing** — how to add a new agent or skill.
